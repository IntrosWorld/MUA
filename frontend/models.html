Quick setup

Bring your own model.

Ollama

Install Ollama and start its local server. Pull a model in your terminal, then refresh the list.

ollama pull llama3.2:3b

LM Studio or llama.cpp

Start an OpenAI-compatible local server. Set its API address, including the /v1 path, and choose a loaded model.

http://127.0.0.1:1234/v1

Where your data goes

Ollama and Local API accept localhost addresses only. Your chat and profile context are sent to that runtime. Gemini is an optional cloud provider.

Voice synthesis uses online TTS. Speech models may download on their first run. Smart-home controls currently update simulated device states.
